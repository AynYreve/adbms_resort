# adbms_resort
Webapp for Resorts. Contains user interface and admin dashboard.

This uses Java, Javascript, HTML, CSS, and SQL. 
Java is used for the backend while Javascript, HTML, and CSS is used for the frontend.
This was done by a team but the backend and database connection is done by me. 
The pictures are entirely placeholder and is not used for commercial purposes.

You can access the admin panel by creating an account in the register page, setting the role manually in MySQL into 'admin', and enter your admin's username and password.
